# Лабораторія безпеки IoT

Папка містить конфігураційні шаблони й документацію для власної локальної лабораторії. Не скануйте та не тестуйте чужі системи без явного дозволу. Приватні ключі генеруються локально і ніколи не додаються до Git.

## План
1. PKI: root/intermediate CA, X.509 device certificates, CRL/OCSP, certificate pinning і ротація.
2. MQTT: TLS/mTLS, окремі ідентичності й ACL за топіками, захист від повторів на рівні застосунку.
3. Firmware: Secure Boot V2, підписані OTA, anti-rollback; апаратні зміни перевіряти на тестовій платі.
4. Мережа: сегментація IoT VLAN, VPN gateway, firewall із забороною за замовчуванням.
5. Аудит: STRIDE, перевірка лише локальної лабораторної системи, журналювання та план реагування.

Симулятор не реалізує криптографічний CoAP/MQTT або апаратний Secure Boot. Шаблони треба звірити з версіями брокера, ESP-IDF та конкретною платою.
