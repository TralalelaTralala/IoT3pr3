# План локальної перевірки безпеки

Обсяг: лише власний симулятор, localhost та окрема тестова мережа. Не сканувати публічні адреси, мережі закладу чи пристрої без явного дозволу.

1. Огляд конфігурацій: відсутність ключів у Git, мінімальні TLS версії, anonymous MQTT вимкнений, ACL обмежує топіки.
2. Перевірка TLS на локальному тестовому брокері: валідний клієнт, невідомий CA, прострочений/відкликаний сертифікат, неправильний hostname; очікувати відмову з'єднання у негативних випадках.
3. MQTT ACL: кожен вузол читає/пише тільки власні дозволені топіки; перевірити заборону чужого namespace.
4. Повторне повідомлення: повторити тестовий sequence/nonce; application layer має відхилити replay.
5. Firmware: перевірити підпис image і сценарій відкату в емуляторі/тестовій платі; не змінювати eFuse до збереження recovery plan.
6. Локальний сканер/проксі може використовуватись лише проти власного ізольованого хоста. Фіксувати інструмент, версію, дату, scope, результат і remediation.

Не запускати автоматичні exploit-скрипти проти реальних пристроїв. Записувати лише відтворювані результати з лабораторної системи.
