# План реагування на інцидент

1. Ізолювати вузол або мережевий сегмент, не видаляючи журнали.
2. Зафіксувати час, device ID, сертифікат fingerprint, топік і подію. Не копіювати секретні ключі в звіт.
3. Відкликати сертифікат пристрою в CA та оновити CRL/статус; обмежити ACL відповідного identity.
4. Перевипустити ключ/сертифікат і прошити перевірений підписаний образ через довірений канал.
5. Перевірити цілісність gateway/broker, журнали та інші пристрої; відновлювати сегмент поступово.
6. Зберегти timeline, оцінити вплив, записати corrective actions та lessons learned.
