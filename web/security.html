Локальний аудит

Завантаження…
Показано результат статичного огляду локальних конфігурацій; мережевий penetration test не виконувався.

    Практична перевірка захисту повідомлень

    Перевірка виконується в локальному емуляторі: сервер приймає справжній HMAC-SHA-256, відхиляє повтор nonce/sequence та підроблений payload. Ключ тесту створюється у пам'яті й не записується у файли.

    Перевірку ще не запускали

    TLS/mTLS MQTT, сертифікати для пристроїв, VPN і Secure Boot лишаються окремими компонентами: для них потрібні брокер, мережевий стенд або ESP32.

    Безпечна область демонстрації

    Демо обмежене локальним застосунком і не сканує мережі, не змінює firewall і не прошиває фізичний ESP32. Конфігурації TLS, VPN та Secure Boot підготовлені як навчальні артефакти; вони не видаються за активний захист реального обладнання.
