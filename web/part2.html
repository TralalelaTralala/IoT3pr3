LoRaWAN · EU868 · Class A

OTAA показано як демонстраційний стан; ADR змінює SF і потужність за RSSI. Дані та дальність змодельовані.

Компактний payload:

Zigbee mesh · координатор + 2 маршрутизатори + 3 кінцеві вузли

CoAP ресурси (JSON)

RFC 7252: демонстрація структури ресурсу й відповіді Content.
Observe/Block-wise вказані у моделі протоколу; сервер UDP CoAP у цій збірці не піднімається.

Енергетична оцінка

Розрахунок моделі за припущеними струмами, не вимірювання реальної плати.

Актуатори Zigbee

Обмеження демонстрації

Симулятор показує архітектуру, формати, маршрути, резервування й тестові сценарії. Для фізичних вимірювань потрібні ESP32 + SX1276/RFM95, Zigbee-вузли, CoAP UDP-стек, антени та вимірювач струму. Значення RSSI, втрат пакетів, струму й часу роботи позначені як оцінні.
